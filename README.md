# 可转债持有人 & 历史下修查询系统（kezhuanzhai）

一个面向可转债（可转换公司债券）投资者的轻量级查询工具：输入转债代码，即可查看该转债的
**历次报告期十大持有人 / 基金持仓**，以及 **历史下修记录（下修次数、下修时间、下修提议）**。
数据来自公开披露平台的聚合，首次查询自动抓取入库，之后直接读库、不再重复爬取。

> 在线示例（如有）：http://kzz.qikankan.com

## 功能特性

- **十大持有人 / 基金持仓**：按报告期展示历次十大持有人，标注性质（基金 / 一般机构 / 个人）、
  持有数量（万张）与占比；含自然人持仓市值估算。
- **历史下修记录**：
  - 下修次数、最近一次下修的**股东大会日**与**生效日**；
  - 独立 SEO 专题页 `/xiuxie/<code>`，含结构化数据（Breadcrumb / FAQ JSON-LD）、canonical、OG 标签；
  - 转债详情页与首页搜索结果均提供「查看下修记录」入口。
- **首页搜索**：支持代码 / 名称 / 拼音首字母检索全市场转债；命中后直接跳转详情页，
  并显示「转债详情」「下修记录」两个快捷链接；首页展示「最近检索的可转债」快捷入口。
- **数据更新**：详情页若数据非当日更新，显示「更新数据」按钮，一键重新拉取该转债最新信息。
- **管理后台** `/admin`：单只 / 批量更新、删除转债及其持有人数据（账号见下方配置）。
- **搜索引擎友好**：详情页 / 下修页 / sitemap.xml 均做基础 SEO 优化。

## 技术栈

- 后端：Python 3.10+ / Flask 3.x
- 存储：SQLite（单文件数据库 `cb_holders.db`，运行时自动生成）
- 数据源：东方财富数据中心（十大持有人、基础资料）、集思录（历史下修 `adj_logs`）
- 前端：Jinja2 模板 + 原生 CSS（无构建步骤）

## 安装与运行

```bash
cd cb_holder_system
pip install -r requirements.txt
python app.py
```

打开 http://127.0.0.1:5000 （开发默认端口 5000）。

- **首页**：输入转债代码（如 `127061`）或名称 / 拼音首字母查询；未收录则自动爬取入库。
- **管理后台**：http://127.0.0.1:5000/admin ，默认账号 **admin / admin888**。

### Windows 一键启动

双击 `start_flask.bat` 即可（已内置 venv 解释器路径与自动重载，适合本机部署）。

## 数据播种（可选，推荐）

首次部署后，建议先跑播种脚本，把全市场基础资料与下修记录预拉入数据库，
这样首页搜索与下修页可直接命中、无需逐只触发抓取：

```bash
python seed_bonds.py          # 全市场基础资料（断点续跑）
python seed_down_revise.py    # 全市场历史下修（限速 + 断点续跑）
```

> 两个脚本均带断点续跑与限速，中途中断可重试。

## 配置说明（`config.py`）

| 配置项 | 说明 |
| --- | --- |
| `ADMIN_USER` / `ADMIN_PASS` | 管理后台账号密码，默认 `admin / admin888`，**生产请务必修改** |
| `SECRET_KEY` | Flask 会话密钥，可用环境变量 `CB_SECRET_KEY` 覆盖 |
| `CACHE_TTL_DAYS` | 已采集数据超过该天数则提示「较旧，建议更新」（默认仍返回缓存） |
| `EM_BASE` / `EM_HEADERS` | 东方财富数据中心接口与请求头 |
| `THS_BASE` | 同花顺 F10（best-effort，校正最新一期持有人性质） |

## 数据来源与口径

- **东方财富数据中心** `RPT_BOND_CB_HOLDER`：各报告期十大持有人（权威、免费、含全历史），
  返回 `HOLD_NUM`（单位：张）→ 自动 ÷10000 转为「万张」。
- **东方财富数据中心** `RPT_BOND_CB_LIST`：转债名称、正股、评级、发行规模、到期日等基础信息。
- **集思录** `adj_logs`：历史下修记录（下修前 / 后转股价、下修底价、股东大会日、生效日）。
- 同花顺 F10（best-effort）：校正最新一期「持有人标识」性质（基金 / 一般机构 / 个人）。

> 可转债十大持有人仅在年报、半年报披露，故数据天然有约半年时滞；一季报 / 三季报通常不含该表。

## 字段说明

- 性质（基金 / 一般机构 / 个人 / 未知）：东方财富不直接提供，本系统**按持有人名称规则推断**，
  并用同花顺「持有人标识」对最新一期做校正。个别机构管理的专户可能误判，属正常误差。
- 交易所后缀规则：代码以 `11` 开头 → 上交所 `.SH`；以 `12` 开头 → 深交所 `.SZ`。

## 部署提示

- 生产环境建议使用 `gunicorn` 等 WSGI 服务器托管，并以反向代理（Nginx / Caddy）对外暴露。
- 务必通过环境变量或配置修改 `SECRET_KEY` 与管理员密码，避免默认值上线。
- 公开部署时注意数据源的访问频率限制与 robots 合规。

请自行评估相关授权与合规要求。
